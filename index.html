Featured Project 01 / 06

ICASSP 2026 · 제1저자 · Oral석사 연구특허 출원

DNA Multi-LoRA: 노이즈 인지 기반 동적 어댑터 적응 방법론

입력 음성의 잡음 유형을 먼저 분류하고, 그 잡음 도메인에 맞게 학습한 LoRA 어댑터를 동결된 탐지 모델에 붙여 실환경에서도 성능을 유지하는 딥페이크 음성 탐지 기법입니다.

Problem

깨끗한 음성에서 높던 탐지 성능이 배경 소음·잔향·압축 등 실환경 조건에서 크게 떨어집니다. 새 조건에 Fine-tuning하면 기존 성능을 잊고, 환경별 모델을 두면 비용이 커집니다.

Approach

  • Spectrogram·MFCC·F0 세 갈래 특징을 CNN-BiLSTM으로 융합한 9-way 잡음 분류기
  • 잡음 도메인별 LoRA 어댑터를 라우팅해 추론 시 적용
  • AASIST-SSL, Conformer+TCM 백본에서 검증

Result

  • 평균 EER 31.6% 상대 감소
  • 학습 파라미터 26.7M (Full FT 317.8M 대비 약 1/10)
  • 잡음 분류기 외부 데이터 정확도 95%
  • 석사학위논문 · 국내/미국 특허

Stack · PyTorch · wav2vec 2.0 (XLSR) · LoRA · CNN-BiLSTM · ASVspoof 2019/2021 · In-the-Wild

Featured Project 02 / 06

WISA 2026 · 제1저자 · OralExplainable AI

FLEX: Frame-Level Explanations for Audio Deepfake Detection

탐지 모델을 다시 학습하지 않고, 음성의 어느 프레임이 Real 또는 Fake 판단에 가까운지를 점수로 보여 주는 사후 설명 기법입니다.

Problem

탐지 모델은 음성 전체에 대해 Real/Fake만 알려 줄 뿐, 어느 구간을 근거로 판단했는지 설명하지 못합니다. 부분적으로 위조된 음성에서는 특히 근거가 중요합니다.

Approach

  • 동결된 SSL 탐지 모델에서 프레임 임베딩 추출·정규화
  • 클래스별 k-means로 Bonafide/Spoof 프로토타입 구성
  • 예측 클래스 프로토타입과의 최소 거리를 0~1 정렬 점수로 변환

Result

  • FLEX가 고른 중요 프레임 30%를 가리면 EER이 7.85% → 최대 37.71%로 상승, 덜 중요한 프레임을 가리면 9% 안팎 유지
  • 프로토타입 개수(K 2~32)와 무관하게 일관된 결과
  • SNR 10–30 dB 잡음에서도 중요도 순위가 안정적
  • 역전파 없이 설명 1건당 27.1 ms

Stack · XLSR (wav2vec 2.0) · SSL-AASIST · SSL-Conformer+TCM · ASVspoof 2019 LA · In-the-Wild · k-means

Featured Project 03 / 06

ICASSP 2027 · 제1저자 · 심사 중Audio ForensicsAcoustic Scene Classification

SAFE: 음성이 섞인 녹음에서 환경을 분류하는 포렌식 ASC

녹음 속 배경음으로 녹음 장소를 추정하는 음향 장면 분류(ASC)를 포렌식 증거로 쓰기 위해, 말소리를 억제하면서 장소를 알려 주는 음향 단서는 보존하는 프레임워크입니다.

Problem

실제 수사용 녹음에는 대부분 사람의 말소리가 함께 담겨 있습니다. 말소리가 배경음을 가리면 장면 분류 성능이 크게 떨어지고, 기존 음성 억제기는 분류 모델과 따로 학습되어 장면 단서까지 지울 수 있습니다.

Approach

  • 깨끗한 장면으로 ASC 모델을 학습한 뒤 동결해 교사로 사용
  • 음성 억제 네트워크를 복원·표현 보존·분류 손실로 교사 지도 학습
  • 추론 시 억제된 장면을 동결 ASC 모델로 분류

Result

  • SBR 10 dB에서 억제 미적용 대비 macro-F1 평균 20.2% 상대 향상
  • 기존 음성 제거·억제 기법 대비 두 데이터셋 모두 최고 macro-F1
  • 다양한 SBR·발화 길이·억제 백본에서 일관된 개선
  • CochlScene, TAU2019로 평가

Stack · PyTorch · STFT 마스킹 기반 음성 억제 · Teacher-guided training · macro-F1 · SI-SDR

음성 제거·억제 기법 비교 · SBR 10 dB (높을수록 우수)

Featured Project 04 / 06

N사 기술이전 · 약 1억 6,500만 원방송 시연국가연구개발 우수성과 100선

딥페이크 음성 탐지 웹 서비스 및 On-Premise 배포

연구한 탐지 모델을 웹 서비스와 추론 API로 직접 구현하고, Docker 기반 On-Premise 시스템으로 패키징해 기술이전까지 이어 갔습니다.

Problem

연구 모델은 연구실 서버의 스크립트로만 동작했습니다. 방송 촬영과 전시에서 반복 시연하자 연속 요청 시 GPU 메모리 증가와 추론 지연이 발생했습니다.

Approach

  • 업로드 → ffmpeg 추출 → 추론 → 구간별 결과·파형 시각화 파이프라인
  • 추론 기능을 API로 분리해 웹과 모델 실행의 의존성 축소
  • 모델 로딩 구조 개선, Docker 컨테이너로 패키징

Result

  • KBS·MBC·MBN·SBS 방송 촬영과 국내외 전시에서 반복 시연
  • 음성 탐지 시스템을 On-Premise로 패키징해 N사에 기술이전

Stack · PyTorch · fairseq/wav2vec2 · Flask · Gunicorn · Docker · CUDA · ffmpeg

Featured Project 05 / 06

경찰청 R&D대학 3곳 · 기업 1곳독일 LKA 제공

멀티모달 통합 탐지 시스템 구축

'허위조작 콘텐츠 진위여부 판별 시스템 개발' 과제에서 기관별 음성·영상·이미지·텍스트 탐지 모델을 하나의 시스템으로 통합했습니다.

Problem

기관마다 API 입출력 규격과 변경 시점이 달라 연동 문제가 반복됐습니다. 온프레미스 이전 때는 라이브러리·의존성 차이와 '완료' 기준 차이로 통합이 지연됐습니다.

Approach

  • 음성 탐지 모델·API를 개발해 통합 시스템에 제공
  • 기관별 API 조건과 변경 이력을 문서화하고 인터페이스 표준화
  • MLOps 흐름을 학습해 기관별 수정 사항·일정 조율

Result

  • 1차 멀티모달 통합 시스템 직접 구축
  • 여러 탐지 기술을 하나의 온프레미스 시스템으로 연결
  • 완성된 시스템을 독일 LKA에 제공

Stack · React · FastAPI · Celery · Redis · Docker · PyTorch · Gunicorn
