Project 01 / 06 · Research

ICASSP 2026 · 제1저자 · Oral석사 연구국내·미국 특허

DNA Multi-LoRA 노이즈 인지 기반 동적 어댑터 적응 방법론

입력 음성의 잡음 유형을 먼저 분류하고, 그 잡음에 맞게 학습한 LoRA 어댑터만 동결된 탐지 모델에 붙여 실환경에서도 탐지 성능을 유지합니다.

논문 (IEEE Xplore)GitHub 코드

Problem

배경 소음·잔향·압축 같은 실환경 조건에서 탐지 성능이 크게 떨어집니다. 새 조건에 맞춰 다시 학습하면 기존 성능을 잊고, 환경마다 모델을 두면 비용이 커집니다.

Approach

Spectrogram·MFCC·F0를 융합한 CNN-BiLSTM으로 9가지 잡음 유형을 분류하고, 해당 잡음 도메인의 LoRA 어댑터를 골라 탐지 모델에 적용합니다.

Project 01 / 06 · Result

DNA Multi-LoRA 실험 결과

Result
약 1/10의 학습 파라미터로 두 백본 모두 Full Fine-tuning보다 낮은 EER을 기록했고, 평균 EER을 31.6% 상대 감소했습니다. 이 결과는 석사학위논문과 국내·미국 특허로 이어졌습니다.

Project 02 / 06 · Research

WISA 2026 · 제1저자 · OralExplainable AI

FLEX 프레임 단위로 딥페이크 판단 근거를 설명하는 기법

탐지 모델을 다시 학습하지 않고, 음성의 어느 프레임이 Real 또는 Fake 판단에 가까운지를 점수로 보여 줍니다.

Problem
탐지 모델은 Real/Fake만 알려 줄 뿐, 판단 근거가 된 구간을 설명하지 못합니다.
Key Finding
발화 단위로만 학습한 모델이어도, 프레임 단위 표현이 Real/Fake 클래스별로 구분됩니다.
Approach
그래서 각 프레임이 예측 클래스 프로토타입에 가까울수록 중요한 프레임으로 점수를 매기는 FLEX를 제안했습니다.

Project 03 / 06 · Research

ICASSP 2027 · 제1저자 · 심사 중Audio Forensics

SAFE 음성이 포함된 녹음에서 녹음 환경을 분류하는 포렌식 기법

배경음으로 녹음 장소를 추정하는 장면 분류에서, 음성은 억제하고 장소 단서는 보존합니다.

Problem

수사용 녹음에는 대부분 음성이 섞여 있어 배경음 단서가 가려지고, 장면 분류 성능이 크게 떨어집니다.

Approach

깨끗한 장면으로 학습한 분류 모델을 동결해 교사로 두고, 음성 억제 네트워크를 복원·표현 보존·분류 손실로 지도 학습합니다.

Project 04 / 06 · Engineering

N사 기술이전 · 약 1억 6,500만 원방송 시연우수성과 100선

딥페이크 음성 탐지 서비스 웹 서비스 개발 및 On-Premise 배포

Problem
연구 모델이 연구실 서버의 스크립트로만 동작했고, 반복 시연 중 연속 요청 시 GPU 메모리 증가와 추론 지연이 발생했습니다.
Approach
업로드 → ffmpeg 추출 → 추론 → 구간별 결과·파형 시각화 파이프라인을 만들고, 추론을 API로 분리해 모델 로딩 구조를 개선했습니다.
Result
KBS·MBC·MBN·SBS 방송과 국내외 전시에서 반복 시연했고, Docker 기반 On-Premise로 패키징해 N사에 기술이전했습니다.

Project 05 / 06 · Engineering

경찰청 R&D대학 3곳 · 기업 1곳독일 LKA 제공

멀티모달 통합 탐지 시스템 허위조작 콘텐츠 진위 판별 시스템 개발

Problem
기관마다 API 입출력 규격과 변경 시점이 달라 연동 문제가 반복됐고, 온프레미스 이전 때는 의존성 차이와 '완료' 기준 차이로 통합이 지연됐습니다.
Approach
음성 탐지 모델·API를 개발해 제공하고, 기관별 API 조건과 변경 이력을 문서화해 인터페이스를 표준화했습니다. MLOps 흐름을 익혀 기관별 수정 사항과 일정을 조율했습니다.
Result
1차 멀티모달 통합 시스템을 직접 구축했고, 여러 탐지 기술을 하나의 온프레미스 시스템으로 연결해 독일 LKA에 제공했습니다.
